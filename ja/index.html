スキル

Python

研究で最もよく使う主要言語です。深層学習、コンピュータビジョン、ロボット制御、データ処理、自動化に、NumPy や OpenCV などのライブラリとあわせて活用しています。

深層学習

PyTorch を用いて、分類・セグメンテーション・ラック穴の占有予測などの認識タスク向けにニューラルネットワークを設計・学習しています。SAM2 などの基盤モデルをゼロショットのセグメンテーションに応用した経験があります。

コンピュータビジョン

OpenCV による画像処理とマシンビジョン。古典的な手法から深層学習ベースの検出・セグメンテーションまで扱い、ロボットの認識のためにデータの自動収集・クラスタリング・ラベリングを行うパイプラインを構築しました。

ロボットマニピュレーション

実験室の自動化に向けて、ロボットアーム（UFactory xArm Lite6 など）上で視覚誘導型のピックアンドプレースシステムを開発し、認識・計画・制御を実機で統合しています。

動作計画

ピックアンドプレースや再配置タスクのために、衝突のないアーム動作を計画します。タスクレベルのプランナと動作レベルの計画を閉ループで組み合わせ、ロバストな実行と再計画を実現しています。

強化学習

D3QN や分散学習などの深層強化学習を、多物体の再配置といったタスクレベルの計画問題に適用し、シミュレーションと実機実験の両方で検証しています。

3D 認識

Intel RealSense などの RGB-D カメラと点群データを用いて、マニピュレーションのための物体位置推定、カメラキャリブレーション、ロボット搭載センシングに取り組んでいます。

信号・画像処理

光電子工学のバックグラウンドで培った信号とシステム、ディジタル画像処理、光学工学の基礎が、イメージングと認識システムの研究を支えています。

C

工学系の学部教育で身につけた C 言語の基礎。授業課題、マイコンやハードウェア関連のプログラミング、アルゴリズムの練習に使ってきました。

Linux

開発と実験のための Linux 環境に慣れています。シェルスクリプトの作成、深層学習環境の構築、ロボットソフトウェアの実行などを行っています。

Git

研究コードのバージョン管理と GitHub での共同開発。ブランチ運用やコードレビューの経験があります。

LaTeX

LaTeX による論文・技術文書の執筆と組版。RA-L や IJRR などのロボティクス系ジャーナルの査読プロセスを経験しています。

論文

Robotic Test Tube Rearrangement Using Combined Reinforcement Learning and Motion Planning in a Closed Loop
The International Journal of Robotics Research (IJRR) 2026年3月
Hao Chen Yu Tang Weiwei Wan Masaki Matsushita Jun Takahashi Takeyuki Kotaka Kensuke Harada

多種類の試験管をラック内で再配置する問題に対し、強化学習（RL）と動作計画を組み合わせたフレームワークを提案しています。RL はタスクレベルで入れ替え動作の系列を計画し、動作計画はそれに基づいてロボットのピックアンドプレース動作を詳細に生成します。両者はラックの各穴に対して維持される条件集合を介して閉ループで結合され、失敗が生じても効率的に再計画できます。RL には分散型の深層 Q 学習と Dueling Double DQN（D3QN）を用い、A* ベースの後処理で学習データを増強・整理することで、学習効率とデータの有効性を高めています。シミュレーションと実機実験により、RL と後処理の利点、および閉ループ結合によるロバスト性の向上を確認しました。

Zero-Shot Recognition of Test Tube Types by Automatically Collecting and Labeling RGB Data
IEEE Robotics and Automation Letters (RA-L), vol. 10, no. 8, pp. 8276-8283（ICRA 2026 で発表） 2025年8月
Yu Tang Weiwei Wan Hao Chen Masaki Matsushita Jun Takahashi Takeyuki Kotaka Kensuke Harada

実験室のラックに置かれた試験管の種類を自動で検出・認識するゼロショットのパイプラインを提案しています。ラック穴の占有予測、自動セグメンテーション、クラスタリング、ラベリングを組み合わせることで、人手で用意した学習データセットを不要にします。ニューラルネットワークがラック穴の占有状態を予測し、SAM2 によるセグメンテーションと HDBSCAN によるクラスタリングで試験管のキャップを自動分類します。未知の種類の試験管に出会うと認識ライブラリを逐次拡張するため、明示的な学習データなしで柔軟なロボットマニピュレーションが可能です。RealSense D405 カメラと UFactory xArm Lite6 ロボットを用いた実験で、実際の検査室環境におけるロバストな性能を示しました。
